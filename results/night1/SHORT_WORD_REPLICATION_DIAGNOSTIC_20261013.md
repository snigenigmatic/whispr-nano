# Secondary diagnostic: acoustic replication for isolated-word recognition

Recorded while both short-Hindi runs are still in progress, before inspecting their prediction content or quality summaries. This is a secondary, exploratory analysis of the already scheduled recordings and requires no new GPU inference.

The 102 selected source recordings each have a one-word task reference. Compare the original short waveform with the already constructed five-copy and eight-copy waveforms. For this **isolated-word recognition task only**, return the most frequent normalized hypothesis token, resolving a tie by its first occurrence. Return empty if decoding emits no normalized tokens. Apply exactly the same output rule to original, five-copy and eight-copy conditions; otherwise an apparent gain could come merely from imposing a one-word output format. Gold word identity is never passed to decoding or output selection. The single-word task is assumed, not inferred from a hidden reference in deployment.

Report exact-word accuracy, paired speaker-bootstrap accuracy differences, how many previously correct words become wrong, how many wrong words become correct, and the measured inference-time multiplier on the same GPU. Five copies are the primary replication diagnostic; eight are a secondary dose check. Both must be reported. No tuning of copy count, spacing, token selector or examples on these outcomes. These 102 source recordings have one speaker each. All remain drawn from the same benchmark as earlier work, so evidence would be exploratory, not an external test.

This is not a general transcription repair and must never be applied to natural multiword or genuinely repeated utterances. It knowingly reduces output to one word because of the explicitly specified recognition task. A gain would justify a later, separate evaluation on the remaining source recordings; it would not establish publication novelty, Indian-English transfer, latency suitability, or equivalence to a larger model. A failed diagnostic is retained. We make no novelty claim for audio replication or voting.
