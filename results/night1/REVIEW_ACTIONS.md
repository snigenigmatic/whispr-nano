# What to show on 16 October, and what still needs evidence

This pilot is a completed, reproducible public-corpus result, **not yet a publishable paper**. Present the measured decoder-setting failure and the data-quality audit from [`RUN_REPORT.md`](RUN_REPORT.md). Do not present the automatic script lexicon as a model improvement or the HiACC adult/child slice as a fairness result.

| Work | Concrete completion criterion | Suggested owner |
|---|---|---|
| Listen to flagged audio | Start with the ten seed-selected items in [`prediction_qc_examples.md`](prediction_qc_examples.md), then sample more from [`prediction_qc_flags.csv`](prediction_qc_flags.csv). Record whether the speech, released transcript, segment boundary, or decoder caused each discrepancy. | Two bilingual team members |
| Validate script pairs | Review all 129 `AUTO_ACCEPT` pairs in [`lexicon_v0.csv`](lexicon_v0.csv) plus high-frequency `COLLISION` pairs such as `click`/`क्लिक`. Record approve/reject/ambiguous and have a second reviewer independently label a shared subset. Re-score the frozen cluster-heldout partition with only approved pairs. MUCS clusters are recordings/tutorials, not verified people. | Two bilingual team members; agent can rerun scoring |
| Validate terms | Correct the 200 candidate annotations in [`annotations_heuristic_v0.jsonl`](annotations_heuristic_v0.jsonl) while blinded to ASR output. The fixed sample has only 53 MUCS and one HiACC candidate TERM span; if term analysis remains the paper focus, freeze a term-rich MUCS sample from reference text before looking at its predictions. | Team annotators; agent can prepare queue and rerun TermER |
| Validate the observed loop failure | On 405 disjoint-speaker Lahaja clips, Whisper-small greedy scored **119.73% WER**; the development-frozen, text-only loop rule scored **77.79%** (paired speaker-bootstrap improvement 41.94 points [32.36, 52.14]). Ask two bilingual teammates to listen independently to flagged clips and confirm what was actually spoken. Preserve the 88 changed transcripts and the 4 changed clips with no WER gain for error analysis. | Two bilingual team members; agent can prepare blinded queue and analyze agreement |
| Test an acoustically supported repair | The simple text rule would alter 960/1,440 perfect genuine-repetition references in an independent benchmark, so it is not a deployable general ASR fix. Develop a gate using only development audio and model outputs, then test on both Lahaja held-out speakers and true repeated speech. Keep the pinned Turbo 39.09% WER reference, five-beam control, WER, false suppression, term/number fidelity, latency, and memory visible together. | Agent |
| Make the paper claim | Use the 16 October review to choose the supported direction. A submission needs an acoustic gate or other defensible intervention, independent-corpus testing that covers Indian English/Hinglish, reviewed labels, and listening-checked errors. The current result is a strong failure analysis, not a publishable method by itself. | Kaustubh and guide |
