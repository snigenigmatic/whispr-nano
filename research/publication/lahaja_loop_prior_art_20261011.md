# Repetition repair: prior art and a safety counterexample

**11 October 2026.** The development result for Whisper-small on Lahaja is real but should not be called a novel or generally safe ASR method. [Jasiński et al.](https://www.alphaxiv.org/pdf/2606.23060) already discuss reference-free repetition measures for Whisper hallucination detection, so counting output loops is established. [Zolkepli's Whisper study](https://www.alphaxiv.org/pdf/2609.32560) explicitly evaluates both hallucination suppression and recovery of genuinely spoken repetitions; optimizing only one side can erase real speech. The latter group's [public benchmark](https://huggingface.co/datasets/Scicom-intl/Whisper-Hallucination) supplies a `reduplication` test configuration with 1,440 synthetic audio clips and exact repeat counts.

As a structural counterexample, we applied our **already frozen** five-adjacent-word rule to the benchmark's *perfect reference transcripts*, without running an ASR model on its audio. The rule changed **960/1,440** references: every example with 5, 6, 8 or 12 repeats, and none with 3 or 4. It deleted **6,480 of 9,120 reference words**, equivalent to **71.05% oracle WER** if those otherwise perfect transcripts were postprocessed. [The aggregate receipt](../../results/night1/lahaja_loop_repair_positive_control_20261011.json) pins dataset revision, Parquet hash, policy hash and arithmetic. This is not an observed false-positive rate on real ASR output, but it proves the text-only rule cannot safely serve as a general repetition repair.

The fair next comparison is a gate that checks acoustic support for repeated units, developed without Lahaja held-out speakers and evaluated on both real decoder loops and actually repeated speech. Any paper must report both preservation and suppression, a competitive decoder control, and inference cost. The current Lahaja held-out run tests only whether the simple diagnostic transfers to new speakers; its WER gain, even if large, would not resolve this counterexample.
