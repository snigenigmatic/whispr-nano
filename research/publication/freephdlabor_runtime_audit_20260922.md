# freephdlabor runtime audit

Audit target: `ltjed/freephdlabor` at immutable commit [`9102d18a161037294d3d963b2799351aa724c58b`](https://github.com/ltjed/freephdlabor/tree/9102d18a161037294d3d963b2799351aa724c58b). This is a read-only source audit; the repository was not executed and no credential files were read.

## Executive findings

- The top-level launcher is an online, API-backed Smolagents/LiteLLM application. It loads `.env` with override semantics, defaults the main agents to `gpt-5.6` with high reasoning and medium verbosity, and requires a provider API key selected by the model branch. [`launch_multiagent.py#L28-L43`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent.py#L28-L43) [`launch_multiagent.py#L74-L107`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent.py#L74-L107) [`utils.py#L151-L215`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/utils.py#L151-L215)
- The repository has no runtime dollar budget, spend cap, or provider-budget guard. The nested AI-Scientist code records token usage and computes estimated cost only for a small, old hard-coded model-price table; unknown models log a warning and cost `$0.00`. [`token_tracker.py#L25-L60`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/utils/token_tracker.py#L25-L60) [`token_tracker.py#L107-L136`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/utils/token_tracker.py#L107-L136)
- A single experiment invocation can fan out into two process workers (reduced to the number of visible GPUs), four stages with defaults of 20/12/12/18 maximum iterations, two drafts, two seeds, and retries. The launcher defaults to all four stages. This is a substantial uncontrolled LLM/GPU workload for a fixed external budget. [`bfts_config.yaml#L35-L79`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/bfts_config.yaml#L35-L79) [`run_experiment_tool.py#L120-L149`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/toolkits/run_experiment_tool.py#L120-L149) [`parallel_agent.py#L1168-L1184`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/treesearch/parallel_agent.py#L1168-L1184)
- The experiment tool executes a child Python process locally via `subprocess.run`, inherits the full environment, and passes no Modal/cloud executor configuration. The checked-in Slurm script is only an HPC template and itself assumes a conda environment and H200 GPU. [`run_experiment_tool.py#L261-L314`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/toolkits/run_experiment_tool.py#L261-L314) [`launch_multiagent_slurm.sh#L6-L13`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent_slurm.sh#L6-L13)

## Launcher and model configuration

`launch_multiagent.py` imports Phoenix telemetry, Smolagents' `LiteLLMModel`, `dotenv`, and `litellm`; it calls `load_dotenv(override=True)` and wraps `litellm.completion`. The code writes stdout/stderr logs, then loads `.llm_config.yaml` if present. [`launch_multiagent.py#L9-L43`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent.py#L9-L43) [`config.py#L71-L85`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/config.py#L71-L85)

Precedence is CLI over config over hard-coded defaults, but the CLI override test compares against the same argparse defaults. Thus a config value is retained only when the CLI argument differs from its default. Hard-coded main-agent defaults are `gpt-5.6`, reasoning `high`, verbosity `medium`, and no Claude thinking-token budget. [`launch_multiagent.py#L74-L107`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent.py#L74-L107) The documented config example can independently select a main-agent Claude model and four experiment-tool models. [`README.md#L580-L600`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/README.md#L580-L600)

`create_model` maps Claude to `anthropic/<name>` and reads `ANTHROPIC_API_KEY`; GPT/o-series to OpenAI and reads `OPENAI_API_KEY`; Gemini to `gemini/<name>` and reads `GOOGLE_API_KEY`; Llama to OpenRouter and reads `OPENROUTER_API_KEY`; unknown models fall back to an OpenAI-compatible model with an optional OpenAI key. [`utils.py#L151-L215`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/utils.py#L151-L215)

The launcher copies only five experiment model settings into environment variables (`RUN_EXPERIMENT_*` plus reasoning effort). It does not copy a dollar cap or Modal credentials/configuration. [`launch_multiagent.py#L114-L122`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent.py#L114-L122)

## Agents, loops, and execution surface

The manager is a Smolagents `CodeAgent` subclass with six managed specialist agents (ideation, experimentation, resource preparation, writeup, reviewer, proofreading) and workspace file tools including delete. [`utils.py#L252-L340`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/utils.py#L252-L340) [`manager_agent.py#L146-L178`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/agents/manager_agent.py#L146-L178)

The workspace executor changes the process working directory and delegates execution to Smolagents' `LocalPythonExecutor`; it authorizes the import list supplied by the launcher. This is local code execution, not a remote sandbox or Modal job. [`workspace_executor.py#L14-L52`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/interpreters/workspace_executor.py#L14-L52) [`workspace_executor.py#L57-L96`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/interpreters/workspace_executor.py#L57-L96)

`RunExperimentTool` validates an idea, defaults `end_stage` to 4, copies and rewrites `bfts_config.yaml`, then invokes `launch_scientist_bfts.py` with `--debug`, `--skip_writeup`, `--skip_review`, and the selected end stage. [`run_experiment_tool.py#L120-L149`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/toolkits/run_experiment_tool.py#L120-L149) [`run_experiment_tool.py#L234-L275`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/freephdlabor/toolkits/run_experiment_tool.py#L234-L275)

The nested runner uses a local Python interpreter, an `exec.timeout` of 86,400 seconds per execution, and `ProcessPoolExecutor`. It limits workers to the GPU count when GPUs exist but otherwise leaves the configured worker count. [`bfts_config.yaml#L17-L21`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/bfts_config.yaml#L17-L21) [`parallel_agent.py#L1168-L1184`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/treesearch/parallel_agent.py#L1168-L1184)

Stage progression is an unbounded `while self.current_stage` / `while current_substage` / `while True` loop whose termination depends on stage-completion logic; max-iteration values are used by the agent manager, but there is no global wall-clock, dollar, or token budget. [`agent_manager.py#L697-L727`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/treesearch/agent_manager.py#L697-L727) The configured stage caps are 20, 12, 12, and 18, with `num_workers: 2`, `num_seeds: 2`, and `num_drafts: 2`. [`bfts_config.yaml#L35-L79`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/bfts_config.yaml#L35-L79)

## Actual LLM/provider calls in the experiment tool

The AI-Scientist backend has direct OpenAI and Anthropic clients. OpenAI chat completions use the model string from config and function calling when requested; Anthropic uses `anthropic.Anthropic` and does not support function calling in this backend. [`backend_openai.py#L22-L82`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/treesearch/backend/backend_openai.py#L22-L82) [`backend_anthropic.py#L20-L82`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/treesearch/backend/backend_anthropic.py#L20-L82)

The regular AI-Scientist LLM path uses OpenAI-compatible chat completions for GPT/Gemini and Claude messages for Claude, with exponential backoff on transient provider errors. Calls use `MAX_NUM_TOKENS = 4096` in this helper, while the BFTS YAML separately requests 12,000 code tokens and 8,192 feedback tokens. [`llm.py#L11-L12`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/llm.py#L11-L12) [`llm.py#L80-L118`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/llm.py#L80-L118) [`bfts_config.yaml#L57-L72`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/bfts_config.yaml#L57-L72)

The tracker persists token/cost summaries after the run, but it is observability only: there is no check that compares accumulated cost to a maximum and no stop/cancel action. Its price table covers only several 2024/early-2025 models, while this checkout defaults to newer `gpt-5.6` names; those unknown names are explicitly priced at zero. [`token_tracker.py#L107-L136`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/ai_scientist/utils/token_tracker.py#L107-L136) [`launch_scientist_bfts.py#L35-L39`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/external_tools/run_experiment_tool/launch_scientist_bfts.py#L35-L39)

## Executor/cloud choice and budget conclusion

The only checked-in cloud/HPC-oriented launcher is the Slurm shell template. It requests one H200 GPU, 48 hours, 64 GB memory, activates a local conda environment, and executes the Python launcher through a temporary shell wrapper. There is no Modal SDK, Modal app, or Modal budget enforcement in the inspected launcher, tool, config, or executor paths. [`launch_multiagent_slurm.sh#L6-L15`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent_slurm.sh#L6-L15) [`launch_multiagent_slurm.sh#L33-L45`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent_slurm.sh#L33-L45) [`launch_multiagent_slurm.sh#L75-L103`](https://github.com/ltjed/freephdlabor/blob/9102d18a161037294d3d963b2799351aa724c58b/launch_multiagent_slurm.sh#L75-L103)

For C.Kaustubh's stated constraint (the existing $15 Modal budget is fully reserved and there is no separately authorized LLM API budget), this checkout is not safe to run as-is. Code-verified behavior selects external LLM APIs by default, may invoke four independent model roles inside each experiment run, retries transient failures, and launches local process/GPU work without a spend guard. A safe adaptation would need an explicitly authorized provider and a hard external budget/control layer before any launcher or experiment execution; the repository itself does not supply that control.
