# Svarah native-audio exploratory extension

This is an exposed exploratory corpus, not an untouched confirmation set and not a speaker-disjoint evaluation. The frozen local records show 2,794 prior exposed IDs. The preparer retains that complete ID set and marks whether each output row was previously exposed; it never infers speaker identity from filenames, demographics, transcript, or voice.

Run preparation only after `data/bridge_open/svarah_cache_v1/` contains all three named Arrow shards and `dataset_info.json`. It first checks Arrow row order against the existing 6,656-row pinned metadata by index, audio basename, and exact reference. It records source cache hashes, source shard and row, raw embedded-audio hash, source revision, decoded waveform properties, and all structural flags for all 6,656 records.

If only one confirmed shard can be retrieved, `--available-shard svarah-test-00002-of-00003.arrow` is a separate limited mode. It writes distinct `svarah_native_shard02_v2` and `svarah_input_audit_shard02_v2` directories, maps source rows through a unique `(audio basename, exact reference)` pair without assuming a global Arrow offset, and labels every receipt and config as a limited shard rather than full Svarah. The retired `*_v1` limited outputs are quarantined with an invalidation notice and must never be used for inference: they bound references with a shard-local index rather than the matched global metadata index.

`--available-shard svarah-test-00002-of-00003.arrow --all-available` is a separate availability-selected cohort mode. It writes `data/bridge_open/svarah_native_shard02_full_v1/bundle/` and `research/bridge_open/artifacts/svarah_input_audit_shard02_full_v1/`, and packages every structurally readable row in that one verified shard. It does not apply a duration, clipping, exposure, transcript, or model-result filter. The cohort receipt records its source-shard-only coverage, selected flag counts, exposure count, and the absence of inferred speaker identities. It is not a claim about all 6,656 Svarah rows.

The 12-item smoke bundle is structural-only: longest eligible native waveform at most 40 seconds, followed by eleven IDs with smallest `SHA256('svarah-native-12:' + utt_id)`. Selection does not read transcript content for ranking and does not use ASR output or exposure status. Malformed, silent, or empty-reference rows cannot enter the smoke bundle; no full-audit row is dropped.

The mounted cache retains original audio payloads. The audit records each raw embedded-audio SHA-256; the prepared bundle under `data/bridge_open/svarah_native_v1/bundle/` contains only canonical 16 kHz mono WAVs and references. Any resampling uses `scipy.signal.resample_poly`, with source and canonical hashes retained. Its manifest deliberately points to the future repository-relative staging location `research/bridge_open/svarah_inputs/`. `reference_qc: pass` means only a nonempty structural reference check, never human transcript adjudication.
